## 🎯 Featured Projects

### 🧠 [RAG Document Intelligence Platform](https://github.com/giuliabugatti09/rag-pdf-qa-system)
End-to-end Retrieval-Augmented Generation system for semantic search and Q&A over technical documents. Built with LangChain, LlamaIndex, and ChromaDB.
**Impact:** 88% answer relevancy and 100% context recall (RAGAS evaluation).

### 🦺 [Computer Vision – PPE Detection API](https://github.com/giuliabugatti09/ppe-detection-api)
Real-time PPE compliance detection for industrial environments, served via a FastAPI microservice.
**Impact:** ~80% mAP@50 using a fine-tuned YOLOv8n model.

### ⚙️ [MLOps Pipeline for Predictive Risk Modeling](https://github.com/giuliabugatti09/mlops-churn-project)
Complete ML lifecycle for churn/risk prediction, from experimentation to a deployable inference service with MLflow, Docker, and CI/CD.
**Impact:** 77.9% accuracy / 0.816 ROC-AUC, fully automated training-to-deployment pipeline.

### ☁️ [Cloud Data Engineering Pipeline](https://github.com/giuliabugatti09/bcb-elt-pipeline)
Automated ELT pipeline orchestrated with Apache Airflow, ingesting public API data into a cloud data warehouse with dbt-modeled data marts.
**Impact:** Automated daily ingestion with 13 dbt data quality tests.
